# Student Results Analysis Using Pandas

## Project Description
This project demonstrates data analysis using Python and Pandas. It uses a student dataset containing marks, attendance, age, and city information.

## Operations Performed
- Read and explore CSV data using Pandas.
- Display first and last records.
- Analyze dataset shape, columns, and data types.
- Generate descriptive statistics.
- Calculate average, maximum, and minimum marks.
- Sort and filter student records.
- Calculate total marks and average marks.
- Export the processed dataset to a CSV file.

## Technologies Used
- Python
- Pandas
- Google Colab

## Output
The processed dataset is saved as `output/student_results.csv`.

## Objective
To understand fundamental Pandas operations and gain practical experience in data manipulation and analysis.
